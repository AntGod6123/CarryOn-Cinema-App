# CarryOn Cinema

CarryOn Cinema is a home media hub for your Android device. It brings your personal movie, show, music, and photo collections together, adds rich descriptions and artwork, and lets you play them back on your phone or TV. Friends can also use a simple web page to find songs and line up a karaoke queue while you stay in control on the device.

## What you can do

- **Bring your library together**: Point the app at the folders you want to include, and CarryOn Cinema organizes them into easy-to-browse categories.
- **See rich details**: Movies and shows display titles, summaries, and artwork so you can quickly decide what to watch.
- **Pick up where you left off**: Keep track of what you were watching and continue from the same spot later.
- **Play on your Android device, cast to a screen, or allow a friend to stream through a web browser**: Start playback on your phone or tablet, and get ready to share it on a bigger display.
- **Host karaoke nights**: Guests can open a lightweight web page on your local network to search for songs and add them to the queue.
-  **Watch live streaming TV using M3U8 links.**

## Getting started

1. Video media:
   a. Use these formats: .mp4, .mkv, .avi, .mov, .m4v.
   b. For Movies Libraries, the name of the media is used with The Movie Database or the Open Movie Database for retrieving the images and metadata. The scanner supports the addition of release year (1997) and a resolution such as 1080p in the second portion of the file name. 
3. Music media: The supported audio formats are audio/mp3, audio/flac, audio/aac, and audio/webm, with extensions .mp3, .flac, .m4a, .aac, .wav, and .webm. The directory format must be Music library - Artists - Albums - Track files. Track files can support album track number in the naming scheme.
4. Subtitles: only .srt and .vtt are supported. Subtitles must be in the same folder as the media file. Subtitles in subfolders (e.g., Subs/) won’t be found.
5. Inside the media's folder, use a trailers/ folder and/or name trailer files as trailer or <MovieName> trailer (including -trailer, .trailer, _trailer), optionally with quality or suffix tokens like official, teaser, or 1080p, and ensure the file is a video type for it to be picked up as a trailer.
6. Photos should be organized in subfolders which will be used as the Collection naming scheme.

## Tips

- Keep your device on the same Wi-Fi, Hotspot, or VPN network as anyone using the karaoke web page. 
- If an IOS operating system is used to stream from the webpage the format of the video must be in .265/aac for it to be played with Safari.
- Use your phone's hotspot to share media locally.
